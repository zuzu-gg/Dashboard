# Dashboard del Clima

Dashboard interactivo con React, TypeScript y MUI para consultar indicadores del clima y visualizar los datos por hora de Open-Meteo, siguiendo las guías 8 a 11 completas del Proyecto 03.

- `wikitracker/`: solución oficial de la guía 6, extensión de Chrome.
- `tubetrack/`: ejercicio de TypeScript de la guía 7.
- `src/`: dashboard del clima de las guías 8 a 11.

## Ejecutar el dashboard

```sh
npm install
npm run dev
```

## Ejecutar TubeTrack

```sh
cd tubetrack
npm install
npm run dev
```

## WikiTracker

Cargar la carpeta `wikitracker` como extensión descomprimida desde `chrome://extensions`, como indica la guía 6.

## Publicar el dashboard

```sh
npm run deploy
```
